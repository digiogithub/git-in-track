Implemented on `feat/phase-6-retros-metrics`, alongside GIT-US-0027 in the same
tree. The three channels hang off the existing GoReleaser run: `homebrew_casks:`,
`scoops:`, `dockers:` + `docker_manifests:`, plus a root `Dockerfile` that copies
the binary GoReleaser has already cross-compiled onto `alpine:3.21`.

One decision needs a reviewer's eye: the Homebrew channel is a **cask, not a
formula** (ADR-016), because `goreleaser check` now fails on the deprecated
`brews:` block. Casks do not install on Linux, so the story's first acceptance
criterion is met on macOS only and is left unticked.

Two maintainer actions are required before the next tag, and the release job now
refuses to build without them: create `digiogithub/homebrew-tap` and
`digiogithub/scoop-bucket`, and add the `HOMEBREW_TAP_TOKEN` and
`SCOOP_BUCKET_TOKEN` Actions secrets (fine-grained PAT, `Contents: read and
write`, scoped to one repository each).
