`Workspace.CloseSprint` now freezes the snapshot after `SummarizeClose` and before `applyCarries`, and writes it in the same rev-checked `WriteSprint` that sets `state: closed`; it is skipped for a dry run and for a sprint that already carries one. `Workspace.SprintMetrics` calls `core.SprintMetricsFromSnapshot` before any history is gathered and returns the frozen view when there is one.

Reviewer note: a snapshot-backed metrics answer carries an empty `flow` and `stats` — the cumulative flow diagram is not frozen — so the server and the web UI must omit or label those panels. Tests: `TestSprintCloseFreezesTheSnapshot` in `internal/vault/metrics_test.go`, whose history source fails the test if it is called.
