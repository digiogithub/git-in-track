**Done (GIT-T-0115, GIT-T-0120):** `core.SprintSnapshot` parses, validates and serializes as a `snapshot` block between `retro` and `created`, round-tripping byte-identically including an unknown key inside the block and an unknown future `version`. An open sprint emits no block at all, so ADR-017 still governs everything before the close. `BuildSprintSnapshot` is pure, takes `now` from the caller, produces totals, per-status, per-assignee and per-label distributions and the frozen burndown (observed days only, capped at one point per sprint day), carries the `MetricsProvenance` it froze and forces `approximate: true` for anything but an untruncated git reconstruction. Unresolved references are counted in `totals.unresolved` and reach no distribution. `SprintMetricsFromSnapshot` is the read-side seam, and `TestSnapshotAndLiveMetricsAgree` proves the frozen series equals the live git-reconstructed one point for point on the metrics fixture.
