Landed. `internal/server/api.go` mounts `p.Route("/agent", s.mountAgent)` inside the existing `s.bearerAuth` group, next to `/mcp`. `internal/server/server.go` gains `Options.Agent bool`, `Options.Pando config.PandoTargets`, the `Server.agent *agentState` field built in `New`, and the timeout exemption: `timeoutExceptStream` now also passes through anything under `/api/v1/agent/`, alongside `/events`, `/mcp` and the CORS proxy.

The whole subtree is exempt rather than just `/run`, because `/threads/{id}/stream` is a stream too; the short non-streaming upstream calls carry their own `agentProbeTimeout` (15 s) instead.

Routes: `GET /info`, `GET /health`, `POST /run`, `GET /threads`, `GET /threads/{id}/messages`, `GET /threads/{id}/stream`, `DELETE /threads/{id}`, `POST /runs/{id}/cancel`.

Tests: `TestAgentRequiresCompanionToken` (401 on three routes without the bearer), `TestAgentDisabledReportsNotImplemented` (501 both when the flag is off and when no URL is configured), `TestAgentRoutesAreExemptFromTheRequestTimeout` (drives the middleware directly and asserts no deadline on the agent paths and a deadline on an ordinary one — a 30 s wall-clock test would have been useless).
