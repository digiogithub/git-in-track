Left `in_progress` rather than `done` for the v1.4.0 release, deliberately.

Every story of this milestone is `done` except `GIT-US-0071`, which is `in_review` because one of its acceptance criteria cannot be honestly ticked: it asks that triage work reach no surface and lists search among them, and `Index.Search` deliberately still finds inbox items. ADR-033 scopes the unconditional exclusion to board views, sprint views, sprint candidates and sprint metrics, and an item nobody can find by name is not "real from the moment it is submitted" in the way that ADR promises. `TestSearchStillFindsATriageItem` pins the reasoning and fails if the behaviour changes.

The feature ships in v1.4.0 either way: the inbox, the triage queue and the cycles work are all released. What is open is the wording of one criterion versus the ADR it was written against, which is a decision for a person rather than a change to make on the way to a tag.
