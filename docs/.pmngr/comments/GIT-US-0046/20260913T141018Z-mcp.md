Landed `internal/youtrack`, a native-only, dependency-free YouTrack REST client: 9 source files and 6 test files with golden JSON fixtures under `internal/youtrack/testdata/`. `go build ./...`, `go vet`, `gofmt`, `go test -race ./internal/youtrack/...` and `golangci-lint run ./internal/youtrack/...` are all clean. Nothing imports the package yet — wiring it into the server and the settings UI is the next wave's job.

**Exported surface the next wave writes against.**

Construction and seams: `New(Options) (*Client, error)`; `Options{BaseURL, Token, HTTPClient, Rate, MaxRetries, RetryBase, Now, Sleep, Jitter}`; `Client.BaseURL()`, `Client.String()` (never renders the token). Defaults: `DefaultRate = 5` req/s, `DefaultMaxRetries = 4`, `DefaultRetryBase = 500ms`, `DefaultTimeout = 30s`, `DefaultTop = 100`, `MaxTop = 200`.

Users and projects: `Me(ctx) (User, error)`, `Projects(ctx, query string, page Page) ([]Project, error)`, `AllProjects(ctx, query string) ([]Project, error)`, `Project(ctx, key string) (Project, error)`, `CustomFieldSettings(ctx, projectID string) ([]CustomFieldSetting, error)`, `VersionBundleValues(ctx, bundleID string) ([]VersionValue, error)`.

Issues: `SearchIssues(ctx, query string, page Page) ([]Issue, error)`, `SearchIssuesWithFields(ctx, query, page, fields)`, `SearchAllIssues(ctx, query, page)`, `Issue(ctx, id string) (Issue, error)`, `IssueLinks(ctx, id string) ([]IssueLink, error)`, `Comments(ctx, id string, page Page) ([]Comment, error)`, `AllComments(ctx, id string)`, `AddComment(ctx, id, text string) (Comment, error)`, `Attachments(ctx, id string) ([]Attachment, error)`, `AttachmentURL(Attachment) (string, error)`, `DownloadAttachment(ctx, Attachment) (io.ReadCloser, error)`.

Articles: `Article(ctx, id string) (Article, error)`, `CreateArticle(ctx, ArticleInput) (Article, error)`, `UpdateArticle(ctx, id string, ArticleInput) (Article, error)`, `ChildArticles(ctx, id string) ([]ArticleRef, error)`, `SearchArticles` / `SearchAllArticles`, `ArticleAttachments`. `ArticleInput{Summary, Content *string; ProjectID string; ParentArticleID *string}` — pointers so an update sends only what was set; `ProjectID` is create-only.

Paging and queries: `Page{Skip, Top}` with `Page.Next()`, `EnsureOrderBy(query) string`, `ProjectQuery(shortName, extra) string`, `DefaultSort = "order by: created asc"`.

Errors: `ErrUnauthorized`, `ErrForbidden`, `ErrNotFound`, `ErrRateLimited`, `ErrInvalidInput`, and `*APIError{Status, Method, Path, Body}` which unwraps to the matching sentinel. Bodies are redacted and truncated; a 404 on an `/api/...` path is the "base URL is missing its context path" case the settings UI should word differently from a 401.

Types: `User`, `Project`, `CustomFieldSetting`, `CustomFieldDefinition`, `Bundle`, `VersionValue`, `Issue` (with `Issue.CustomField(name)`), `CustomField`, `CustomFieldValue` (raw JSON with `IsNull`, `IsMulti`, `Values() ([]FieldValue, error)`), `FieldValue`, `IssueLink`, `LinkType`, `IssueRef`, `NonEmptyLinks([]IssueLink)`, `Comment`, `Article`, `ArticleRef`, `Attachment`, `Tag`, `Millis` (unix-ms timestamp with `Time()` and `IsZero()`), the direction constants `DirectionOutward` / `DirectionInward` / `DirectionBoth`, and every `…Fields` selector constant.

**Three things a reviewer must know.** First, `Rate: 0` selects the 5 req/s default and a *negative* rate disables throttling, which inverts GIT-T-0007's wording so that the zero value of `Options` is the safe one; same convention on `MaxRetries`. Second, the mapping layer is deliberately absent — decoding stops at these types, and custom-field values are kept as raw JSON because flattening them is lossy and belongs to the caller. Third, **GIT-T-0014 is still open**: the package doc comment is written, but `docs/02-architecture.md` and `CHANGELOG.md` were outside this agent's file ownership in this wave and still need the entry placing `internal/youtrack` among the native-only packages.
