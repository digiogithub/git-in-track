Landed in the new `internal/server/agent.go`, with `internal/server/agent_test.go` covering every criterion against an httptest stand-in for `pando agui-serve`.

`agentState` holds the resolved `config.PandoTargets`, two lazily built transports (plain and `insecureTls`) and the in-flight semaphore. `relayAgent` is one `httputil.ReverseProxy` per request with `FlushInterval: -1` on the streaming routes; it drops `Origin`, `Referer`, `Cookie` and the browser's `Authorization`, never calls `SetXForwarded`, injects `Authorization: Bearer <pando token>`, strips `repo`/`token`/`access_token`/`api_key` from the forwarded query, removes the upstream CORS headers and sets `Cache-Control: no-cache` + `X-Accel-Buffering: no` on a stream. The inbound request context is passed straight through, so a browser abort cancels the upstream run (test: `TestAgentRunCancelsUpstreamOnDisconnect`).

`handleAgentInfo` is the only non-relay: it fetches `{path}/info` with a 15 s deadline, rewrites every `agents[].url` to `/api/v1/agent/run` and `path` to `/api/v1/agent`, then **deletes** every remaining string anywhere in the document that parses as an absolute URL. `TestAgentInfoRewritesEveryUpstreamURL` asserts the upstream host appears nowhere in the response.

Error paths are RFC 7807 documents written before any stream starts: `invalid_request` (body > 1 MiB, buffered and capped up front), `agent_repo_unknown` 404, `agent_busy` 503 + `Retry-After: 5`, `agent_upstream` 502. An `agent_upstream` detail never echoes the upstream body or names the upstream host; the full error goes to the log. `assertNoTokenLeak` checks the response body, every response header and the captured log for the upstream token on the paths that could carry it.

Reviewer: the flush proof is `TestAgentRunStreamsFrameByFrame`, which holds the second upstream frame until the client has read the first.
