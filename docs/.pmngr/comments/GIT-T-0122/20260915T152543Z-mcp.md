Landed in `internal/pandosync/document.go` with tests in `document_test.go`.

`RenderItem(*core.Item, project)` and `RenderPage(*core.KBPage, project)` emit fenced YAML front matter through `yaml.v3` (so a title holding `:`, `"` or a leading `-` is escaped correctly) in a fixed key order — `id`/`path`, `type`, `title`, `status`, `milestone`, `parent`, `project`, `updated`, `tags`, `aliases` — followed by the identity line `GIT-US-0073 — <title>` (`Page: <slug> — <title>` for a page) and then the body verbatim, so `[[GIT-US-0024]]` wikilinks survive.

Per the 2026-09-13 realignment the identity line is the real carrier of the id: only `tags`/`aliases` round-trip through Pando, so the id also lives in the chunk text. Empty fields are omitted, never written as null (docs/03 §3.2).
