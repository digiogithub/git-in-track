The benchmark is recorded in `docs/research/2026-09-25-spec-impact-benchmark.md`. The criterion
holds against the spec folder.

**How it was measured.** There are 12 PRs:

- 7 real changes from the Phase 11 stack, each replayed as its reverse diff on top of the
  dogfood specs (`GIT-US-0151`, `GIT-US-0106` twice, `GIT-US-0144`, `GIT-US-0122`,
  `GIT-US-0107`, `GIT-US-0148`);
- 5 edits written for the benchmark, one each on the rev protocol, the allocator and MCP
  pagination (two), plus the stale-refusal retry line;
- 2 negative controls, on top of the 12.

Each PR ran in a temporary jj change that was abandoned afterwards. The binary was built from
this change and ran against a throwaway `GINTRACK_CONFIG` with no Pando, so tiers 2–3 were
`unavailable` and there were no candidates. Test results were ingested at the base: 3,325
passed and all 32 requirements were passing. Both sides are measured with `ceil(bytes / 3)`.

**Numbers.**

- **Report size.** The typical report is 225 tokens as the MCP `spec_impact` JSON (median; 751
  at most) and 136 as CLI text.
- **Against the spec folder.** Reading `docs/.pmngr/specs/` costs 8,174 tokens: **36×** the MCP
  JSON, 10.9× in the worst case.
- **Against perfect foresight.** Reading only the one spec file that holds the affected
  requirements gives 8.8× (MCP JSON) and 14.6× (text).
- **Precision of tier 1.** 15 of the 29 hits flag a behaviour change (52 %). 24 of 29 (83 %)
  also count a changed verifying test.
- **Misses.** A package-level constant (`maxPageSize`) and a removed call
  (`registerSpecTools`).
- **Controls.** Both had 0 hits.
- **Determinism.** Two runs of each of six forms (84 pairs) were byte-identical.

**Proposed follow-ups** (§8 of the page; none is required by the criteria):

1. Separate evidence-only hits (reached through test symbols) from behaviour hits.
2. Reach traced symbols through a changed package-level declaration.
3. Document the tier 1–2 blind spots and where to place markers.
4. `spec impact --format json` prints indented JSON, above the `tokens` it reports.
5. Re-run the benchmark with Pando tiers 2–3.
