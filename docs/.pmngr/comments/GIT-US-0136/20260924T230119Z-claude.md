**Notes on what the specs state.**

- `list_items` pages in the core. Its cursor is bound to the sort (`GIT-SP-0004.R5`), not to
  the filter. Only the tools that this package pages itself refuse a cursor presented with a
  changed filter (`R4`).
- `TestItemsPagination`'s subtest "cursor survives an insertion before it" does not insert
  anything, so the specs do not claim that insertion-stable resume is verified.
- The MCP `create_*` and `update_item` tools take no `links` argument, so link validation is
  reached through the vault, the web app and the CLI. The MCP side of `GIT-SP-0003` is the
  requirement `links` of `create_requirement` and `update_requirement`.
