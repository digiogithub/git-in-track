Implemented in jj change on top of GIT-US-0153. `SaveYouTrackLink` still edits the
`integrations.youtrack` node key by key, but now splices only that block's lines back into
the file through the new `core.SpliceYAMLBlock` (replace from the key line to the end of the
block, or insert after the parent's last entry / at end of file), guarded by decode equivalence
and an equal comment multiset. A refused shape (flow-style `integrations`, say) falls back to
the old whole-file re-encode. Regression test:
`TestSaveYouTrackLinkLeavesTheRestOfTheFileByteForByte`; core tests: `TestSpliceYAMLBlock`.

Other yaml.v3 re-encoders of project.yaml, out of scope: the node-tree fallbacks in
`internal/core/allocator.go` (setYAMLPath) and `internal/core/inboxenable.go`
(insertStatusNode), and the fallback kept here. `internal/core/scaffold.go` and
`teamscaffold.go` encode fresh files only.
