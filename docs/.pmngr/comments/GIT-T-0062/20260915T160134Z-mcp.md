Done. `ui/AgentPage.tsx` (three columns: conversations | conversation | rail, collapsing to one below `lg` behind a toggle), `ui/ThreadList.tsx`, `ui/threadMeta.ts` and `ui/model.ts`.

Persistence is derived data only, as specified: `gintrack:agent:threads` holds `{ [repo]: { id, title, updatedAt }[] }` — the key the task names, shaped per repository so it cannot collide with `gintrack:agent-threads:<repo>` and `gintrack:agent-active-thread:<repo>`, which `threads.ts` already owns. Every access is try/catch-guarded (`localStorage` throws in a sandboxed frame). Titles come from the first *user* message, whitespace-collapsed and cut on a word boundary at 60 characters; a transcript that opens with a system prompt or an activity line is not mistaken for one.

`mergeThreadRows` merges the adapter's list (order and `running`) with the local titles and keeps threads the adapter has not heard of yet. Deleting asks once on the row, then calls `deleteThread` and forgets the title. Tests cover title derivation and truncation, persistence across a read, repository isolation, a corrupt file, the merge, and — through `AgentPage` against the fake provider — new / select / delete with the derived title reaching `localStorage`.
