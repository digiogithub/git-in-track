Aligned with the 2026-09-13 decisions after the Pando gap analysis.

Changed:
- Client library is `@pando-ai/sdk/agui`, not `@ag-ui/client` and not a vendored copy (rationale in Notes; CopilotKit stays out).
- Deployment is fixed: one `pando agui-serve` per repository with a companion-side `projectId -> {url, token}` routing table. `pando serve --agui-port` co-mounting and multi-cwd are explicitly ruled out.
- Added the interim restriction posture: HITL + `AutoApprove = false` until the adapter-wide tool allow-list exists.
- Added thread persistence on the git-in-track side (Pando session id reusable as `threadId`), with reload/reconnect called out as blocked.
- New acceptance criterion for a proxy-imposed concurrency cap, per-user and global in-flight — Pando enforces none.
- Recorded the settled identity posture: gintrack owns identity; the Pando token is a service credential, never `?token=`, never in the browser; `AllowedOrigins` empty because the proxy strips `Origin`.
