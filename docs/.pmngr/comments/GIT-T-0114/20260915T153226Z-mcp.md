Written as `docs/adr/ADR-035-agent-interface-over-ag-ui.md` — "The agent panel consumes AG-UI directly, with `@pando-ai/sdk/agui` and our own chat UI". 035 was confirmed as the next free number (`docs/adr/` ended at ADR-034) and the index row was added to `docs/adr/README.md`.

Format follows `docs/adr/README.md`: Status (Accepted), Date, Phase, Related, Implements, Research, then Context / Decision / Consequences / Alternatives considered.

Four alternatives, each with its specific rejection reason:

1. **CopilotKit with a Node sidecar** — a second runtime next to the Go companion, contradicting the single-binary distribution of ADR-005, plus a component library with its own opinions beside the design system of docs/13.
2. **A Go reimplementation of CopilotKit's GraphQL runtime** — substantial protocol code we would own and track against an upstream that is not ours, paid to reach the alternative just rejected.
3. **The generic `@ag-ui/client` `HttpAgent`** — `RunFinishedEventSchema` has no `outcome`, so `outcome: "interrupt"` (the whole HITL design) is invisible to the abstraction, and `EventType` has no `REASONING_*`, so thinking output passes validation and then silently disappears; plus rxjs/zod/uuid/`@ag-ui/proto`/`@ag-ui/encoder` in the bundle, a `process` shim under Vite, and the same custom reducer still needed.
4. **Vendoring `client.ts` + `types.ts`** — kept explicitly as the documented fallback, not the default, because a versioned package is easier to upgrade and audit than an ageing copy.

A fifth, a REST-only non-streaming panel, is recorded too: with `AutoApprove = false` a run that cannot ask for approval cannot use a tool at all.

Both research notes are cited (`docs/research/2026-09-13-pando-gap-sdk-client.md` and `…-pando-gap-agui-server.md`).

Negative consequences listed explicitly, including the two the story demanded: **loopback binding is not a boundary against the user's own browser** while Pando's `:9777` CORS policy is `*` with global auto-approve, and **the persona/skill are conventions rather than enforcement** — `[AGUI] Tools` plus `Mesnada = false` are the real narrowing, the coder agent is what is underneath. Also recorded: the third-party frontend dependency and its exact pin, the young protocol, the operational coupling to a per-project instance holding `.pando/ipc.lock`, the feature being companion-mode only, the companion token landing literally in the repository's `.pando.toml`, and two tabs on one thread fighting server-side.
