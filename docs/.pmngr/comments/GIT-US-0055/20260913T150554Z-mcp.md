Landed: a generic `components/ui/combobox.tsx` (ARIA typeahead, 200 ms debounce, arrow/Enter/Escape, 150 ms blur grace) with `ItemPicker` refactored onto it and no new dependency; five YouTrack methods on `DataProvider` implemented in the companion provider and failing clearly in the browser and fake ones; `YouTrackCard` plus `YouTrackFieldMap` in settings, gated on the new `capabilities.youtrackSupported`.

Reviewer notes: (1) the gate is `youtrackSupported` (companion mode), not `youtrack` (a link already exists) — the latter could never let anyone connect the first project; `Capabilities` therefore carries both. (2) The token field is never seeded and only `hasToken`/`tokenSource` are rendered; a token whose source is `env` or `flag` disables the input and offers no "forget", because it belongs to whoever started the companion. (3) Comment push and KB sync are `<select>`s, not switches: the API values are enums, not booleans. (4) `web`: lint, typecheck and 681 Vitest tests pass; `make lint-web` clean.
