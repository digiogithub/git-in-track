The maintainer approved the approach in PR #39 on 2026-09-24.

Pando already indexes spec files through the KB index, and each hit is matched to its requirement block when it is resolved. That replaces acceptance criterion 1, which asked to feed one derived document per requirement block: that would need `kb_add_document`, which writes to disk and which ADR-036 rejects. Criterion 1 counts as satisfied by this approach.
