Landed in `internal/pando/client.go`.

- One `*mcpsdk.ClientSession` is established lazily on the first call that needs it, guarded by `c.mu`, and shared by every caller afterwards. `acquire` returns a `fresh` flag so `call`/`Health` know a reconnect would be pointless when they just created the session.
- Transport is `mcpsdk.StreamableClientTransport` with `DisableStandaloneSSE: true` (Pando answers `GET /mcp` with 405) and `MaxRetries: -1` (this package does its own single reconnect inside a short deadline).
- The bearer token Pando's MCP HTTP transport now requires is added by `authTransport`, a `http.RoundTripper` on a private `http.Client`. It also records a 401/403 in an atomic flag, because the go-sdk flattens a non-2xx response into a bare error string; `classify` reads that flag instead of matching on text. The REST surface uses a **separate** `http.Client` with no `Authorization` header, so the MCP token can never leak onto it (pinned by a test).
- `call` reconnects exactly once on a dead session: `isSessionDead` covers `mcp.ErrSessionMissing` (Pando answers an unknown session id with 404), `mcp.ErrConnectionClosed`, EOF, `net.ErrClosed` and "connection reset by peer".
- Every call wraps the caller's context in `context.WithTimeout(ctx, c.timeout)`; `Options.Timeout` defaults to `DefaultTimeout` (20s). `classify` maps a deadline to `ErrTimeout`, an auth failure to `ErrUnauthorized` and everything else to `ErrUnreachable`, so a timeout is never confused with a tool error or with an unreachable Pando.
- `Health` does initialize + `tools/list` on the cached session, and reconnects once if that session died. `Close` ends the session and is idempotent; a closed client answers `ErrNotConfigured`.

Tests (`internal/pando/client_test.go`, `fake_pando_test.go`): the stub is a real `mcp.NewServer` served through `mcp.NewStreamableHTTPHandler` behind the same bearer check Pando performs, so the handshake, session id and framing are the SDK's own and only the four tools are faked. `TestSessionIsLazyAndShared`, `TestSessionReconnectsAfterRestart` and `TestHealthReconnectsAfterRestart` (the fake rebuilds its MCP server, which is what a Pando restart looks like from outside), `TestTimeoutIsDistinctFromUnreachable`, `TestUnauthorized`, `TestHealthUnreachable` (fails fast, does not sit on its deadline), `TestCloseIsIdempotentAndFinal`, `TestErrorsDoNotLeakTheToken`. `go test -race ./internal/pando/...` passes.

Reviewer: the reconnect-once logic in `Client.call` and the `fresh` flag are the parts worth reading closely.
