Last open task closed (GIT-T-0039): the mapping table now lives in `docs/03-data-model.md` §12.6, with the three built-in value maps, the link-type directions and R-YT-1 … R-YT-7. The story was already `done`; this only closes its documentation debt.

Two things a reviewer should check, because they are divergences the docs now record rather than hide. An imported item's `external` entry carries **no `key`** — `Options.External` sets only `system`, `id`, `url` and `synced_at` — so the `{system, id, url, key, synced_at}` shape quoted in earlier notes was wrong for issues; only a published KB page records a `key`, and there it holds a content fingerprint rather than §12.5's project key. And `attachments[]` on an imported item holds **full vault-relative paths**, not the bare filenames R-ATT-4 specifies; R-YT-7 documents the divergence and its reason, but someone should decide whether the model or the importer is the one that should change.
