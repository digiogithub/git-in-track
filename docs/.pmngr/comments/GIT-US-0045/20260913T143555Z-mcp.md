Landed `internal/youtrack/mapping` (built on rev cf1cad4): a pure package — no HTTP, no filesystem, no clock — exposing `IssueToDraft`, `IssueToPatch`, `CommentsToDrafts`, `MapLinks`, `NormalizeDescription`, `FieldMap`/`DefaultFieldMap`, `Options`, `Relations` and `Warning`. 96.4% statement coverage; `go build ./... && go vet ./internal/youtrack/... && go test -race ./internal/youtrack/... && gofmt -l internal/youtrack` all clean, and `make lint` reports zero issues in these files.

Two things a reviewer must know. **Nothing that names another item is written onto the draft**: `parent`, `milestone` and `links[]` come back in `Relations` holding YouTrack `idReadable` values and version names, because this package cannot resolve them into `core.ItemID`s — the importer resolves them through `core.Index.ItemByExternal` before writing. And **`core.CommentDraft` has no `external` field** (`core.Comment` does), so `CommentsToDrafts` returns a `mapping.CommentDraft` wrapper carrying the draft, the external reference and the `updated` timestamp beside it; if a later story adds `External` to `core.CommentDraft` the wrapper collapses.
