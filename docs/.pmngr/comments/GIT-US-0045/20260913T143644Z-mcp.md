Follow-up: another agent landed `config.YouTrackLink.FieldMap map[string]string` in `internal/config/projectlink.go`, whose keys (`status`, `priority`, `type`, `assignee`, `estimate`, `milestone`, plus `labels`, `due`, `sprint`) name a git-in-track field and whose values name the YouTrack custom field carrying it. `mapping.FieldMap.WithFieldNames(map[string]string)` consumes exactly that shape, so the importer wires the two with `mapping.DefaultFieldMap().WithFieldNames(link.FieldMap)` and no package depends on the other. `labels`, `due` and `sprint` are ignored: tags already carry the labels and the other two are not mapped.
