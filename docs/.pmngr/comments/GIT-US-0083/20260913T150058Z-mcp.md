The KB content transform landed in `internal/youtrack/mapping/kbpage.go` and `kblinks.go` (plus `kbpage_test.go`, `kblinks_test.go`, `kbgolden_test.go` and seven `testdata/kb-*` files): `PageToArticle`, `ArticleToPage`, `EqualContent`, `PageIndex`/`PageRef`, `ArticlePayload`/`AttachmentRef`, all pure. `go test -race ./internal/youtrack/...` passes and `golangci-lint run ./internal/youtrack/...` is at zero issues.

Reviewers must know three things. **(1)** The publish and pull jobs have to compare with `EqualContent`, never with raw bodies: it ignores the feedback block on both sides, which is what keeps `PruneKbFeedback`'s rewrite from reading as a remote change. **(2)** "Round-trip stable" is idempotence, not identity — a wikilink whose target is not a published page is flattened to text on purpose, so the first pass changes the page and every later pass does not; `TestPageRoundTripIsIdempotent` is the assertion. **(3)** Two acceptance criteria are open because they fall outside `internal/youtrack/mapping/`: the multipart attachment upload (GIT-T-0202, pure half done, transport half not) and the `docs/03-data-model.md` + `CHANGELOG.md` edits (GIT-T-0207). Both tasks carry notes saying exactly what is left.
