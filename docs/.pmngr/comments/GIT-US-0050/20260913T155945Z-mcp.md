Landed as `internal/server/youtrackimport.go` plus the shared plumbing of the four YouTrack job kinds in `internal/server/youtrackjobs.go`; the HTTP surface that starts an import is `POST /api/v1/youtrack/import` (202 with a job id) and `POST /api/v1/youtrack/import/preview` (synchronous plan) in `internal/server/youtrackimportapi.go`.

Two things a reviewer must know. **First**, the handlers are registered in `server.New`, not in `Server.Start`: `Start` replays the journal, so a kind registered after it leaves a restored job undispatchable — `New` is the last moment at which the server exists and nothing is running. **Second**, `classifyYouTrackJobError` exists because `youtrack.APIError` carries its status in a *field* rather than behind a `StatusCode()` method, so `syncengine.Classify` cannot see it: without that translation a rejected token would be retried five times instead of failing at once. Cancellation is returned unwrapped on purpose, so it reads as `cancelled` and not as a failure.
