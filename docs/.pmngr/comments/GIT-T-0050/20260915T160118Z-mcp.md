Done. `ui/MessageList.tsx` + `ui/MessageBubble.tsx`; `isVisible` moved to `ui/model.ts` so the component files export components only (react-refresh lint).

Streaming: the parsed source is throttled to ~120 ms on the trailing edge and the unparsed tail — always a suffix, since text only grows — renders as plain text beside it, with a caret. Shiki highlighting is off while streaming and on once it settles. Markdown goes through `@/markdown`'s public surface with `externalImages: false` and `wikilinks: false`; user messages are escaped plain text.

Auto-scroll follows only while pinned (48 px slack) and offers "Jump to latest" otherwise; the list is `role="log" aria-live="polite" aria-busy`. Tests cover the Markdown render, the sanitisation (a raw `<img onerror>` and `<script>` reach the DOM as neither), the caret appearing and settling, and the live region. The scroll behaviour is **not** asserted: jsdom reports zero for `scrollHeight`/`clientHeight`, so the test would prove nothing.
