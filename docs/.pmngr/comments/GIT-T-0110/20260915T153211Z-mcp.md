It also states plainly that HITL with `AutoApprove = false` is the interim boundary, that loopback binding is not a boundary against the user's own browser (Pando's `:9777` transport is CORS `*` with global auto-approve), that repository content is untrusted data, and that `.pando.toml` carries a secret.
