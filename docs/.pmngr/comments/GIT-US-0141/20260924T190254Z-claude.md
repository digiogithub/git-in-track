Scope addition from the GIT-US-0110 and GIT-US-0116 reviews.

**Both pieces for stamping on done exist, but nothing calls one from the other.**
- GIT-US-0110 (#41) runs `FileStore.DoneHook` / `DoneTransition` inside the done transaction.
- GIT-US-0116 (#42) exposes `stampVerified(ctx, refs, by)` in `internal/vault/reqcoverage.go`. The caller owns begin/commit.

This story should connect them:
- When a story or task moves to done, stamp the requirements it `implements` or `modifies`, using the verify.json evidence (or the GIT-US-0115 result cache until verify.json exists).
- Test it end to end: story → done → `verified:` written only when every linked test passed.

**Avoid `coverage.*` file names.** `.gitignore` ignores that pattern, so new files named that way are silently left out.
