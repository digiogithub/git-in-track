Scope note from the GIT-US-0105 review.

`NextRequirementNumber` (internal/core, from GIT-US-0105) takes max+1 over block headings, map keys and inbound link refs. It does **not** count refs that appear only in a pending `## Spec Delta` (MODIFIED/REMOVED). When this story implements the Spec Delta, make sure:
- Spec Delta refs reserve their numbers during allocation;
- ADDED entries get numbered only when the story reaches `done`, as ADR-037 §9 requires;
- a Spec Delta ref naming an unknown requirement is reported as `W-REF-DANGLING`.
