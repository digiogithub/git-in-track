Eight open decisions closed by the maintainer, 2026-09-16. All are now written into the stories they affect.

**GIT-US-0096.** A comment hit resolves to its parent item, marked as a comment match, several comments on one item collapsing to the best-scoring fragment. A path that is neither a backlog file nor a KB page comes back as a plain file result rather than being dropped silently.

**GIT-US-0098.** The code project is registered from `gintrack serve --agent`, not from `agent init`, so a fresh clone is indexed by starting the server rather than by one person remembering a command. Code hits appear in the web search labelled by origin index. The `docs/*.md` overlap between the two indexations is merged at presentation by file path, keeping the better score, rather than filtered or accepted as duplicates.

**Scope held.** No story is opened against Pando's mirror-write serializer: the `[AGUI] Tools` allow-list is the whole mitigation. Consequence to state in the ADR — the hazard remains live for any repository someone points Pando at with a configuration that did not come from `agent init`, and `kb_add_document` against an existing path still rewrites it with Pando's typed keys alone.

**Sequencing.** GIT-US-0098 proceeds without waiting for PANDO-US-0031: project registration goes over REST, not MCP. Only the allow-list in GIT-US-0097 stays provisional until that deadlock is resolved.

**Milestone.** The epic stays under GIT-M-0013, phase 9, so the phase is not called done until semantic search is the version that ships.
